WEDO Privacy Policy

Effective date: 2024-07-01 · Last updated: 2026-11-23 · Applicable version: v1.1.4 or later (Weather feature officially introduced from v1.2.14)

Prior app versions are governed by the privacy policy in effect at the time of that version's release. See the change log at the bottom of this page.

hoho studio ("the Company") complies with the Personal Information Protection Act (PIPA) of Korea and other applicable laws, and processes the personal information of WEDO users as described below.

1. Categories of Personal Information Processed

1.1 Automatically Collected

ItemHow CollectedRequired / Optional
Anonymous app instance ID, OS version, app version, device modelAutomatically on app launchRequired
IP addressAutomatically on app launchRequired
App usage events (screen views, feature usage — anonymous statistics)Automatically during app useRequired
Crash and error logsAutomatically when an app error occursRequired

1.2 User-Entered Content

ItemHow CollectedRequired / Optional
To-do / checklist textEntered by the userOptional
Group name, group member invitation infoEntered when creating or joining a groupOptional
Background photoSelected from the user's photo library when using the background customization featureOptional

1.3 Permission-Based Collection

ItemHow CollectedRequired / Optional
Location (approximate, city/district level)When using the weather feature, only if the user grants permissionOptional
Photos / media accessWhen using the background customization feature, only when the user selects a photoOptional
Permission Notice — Location and photo permissions are requested at the point of feature use. Declining them does not affect other app features. Permissions can be revoked at any time in your device settings.

2. Purposes of Collection and Use

  • Providing the WEDO service (storing to-dos/checklists and displaying lock-screen widgets)
  • Group sharing (synchronizing shared tasks among group members)
  • Providing weather information based on current location
  • Diagnosing app errors and improving service quality
  • Analyzing usage patterns for usability improvements (anonymous statistics)
  • Delivering important notices and update announcements

3. Retention and Use Period

  • Local app data (to-dos, settings): Stored on the user's device. Deleted along with the app when uninstalled.
  • Group sharing data: Retained on the server while the group exists. When a user leaves or a group is deleted, the user's info is removed from that group; if the group itself is deleted, related data is deleted together.
  • Background photos: Stored locally on the user's device and not transmitted externally.
  • Location data: Used only at the moment of a weather request. Not stored separately.
  • Crash and error logs: 90 days from collection (Firebase Crashlytics retention policy)
  • Anonymous usage statistics: 14 months from collection (Firebase Analytics retention policy)
  • Statutory retention obligations: Retained for the period required by applicable laws, if any.

4. Provision to Third Parties

The Company does not provide users' personal information to third parties. However, when a user uses the group sharing feature, the to-do/checklist text entered by the user is shared with the group members the user has invited. This constitutes voluntary sharing by the user and does not constitute third-party provision.

All transmitted data is protected by TLS encryption in transit. If you object to this transfer, your app use may be limited; you can stop collection by uninstalling the app.

6. Destruction Procedures and Methods

  • Destruction procedure: Personal information for which the purpose of use has been achieved is destroyed without delay.
  • Destruction method:
    • Electronic files: Deleted using a method that prevents recovery
    • Printed materials: Shredded or incinerated

7. User Rights

Users may exercise the following rights at any time:

  • Request access, correction, deletion, or suspension of processing of personal information
  • Revoke location, photo, and other permissions (at any time in device settings)
  • Leave or delete a group (directly within the app)
  • Delete all local data by uninstalling the app
  • For other rights or data deletion requests, contact the address below

8. Automatic Data Collection and Advertising

The app collects an anonymous app instance identifier (Firebase Installation ID) for operational purposes. This is not an advertising ID (AAID).

Advertising — The app displays ads through Google AdMob. For AdMob's data processing, please refer to Google's ad policy. If you do not wish to see ads, you can uninstall the app.

9. Processing of Personal Information of Children Under 14

WEDO is not intended for children under the age of 14. The Company does not knowingly collect personal information from children under 14. If we become aware that a child under 14 has provided personal information, we will delete that information promptly. If a parent or guardian becomes aware that their child has provided personal information, please contact the address below and we will take the necessary action immediately.

11. Changes to This Policy

This privacy policy may be updated to reflect changes in law or the service. We will provide advance notice of changes within the app or on this web page. Please check this page periodically.

If you are a Korean user, you may report or consult about personal information infringement with the following Korean agencies:

  • Personal Information Dispute Mediation Committee (kopico.go.kr / +82-1833-6972)
  • Korea Internet & Security Agency Privacy Report Center (privacy.kisa.or.kr / +82-118)
  • Supreme Prosecutors' Office Cyber Investigation Division (spo.go.kr / +82-1301)

For users outside of Korea, please contact us at support@hohostudio.co.kr for any privacy-related inquiries. You may also contact your local data protection authority.
